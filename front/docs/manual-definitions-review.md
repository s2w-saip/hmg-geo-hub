## 1. 비어있는 정의 (Empty Definitions)

### 1-1. Mention > *브랜드 선택* > 인용 출처 — **정의 공란**
- **위치**: `2-3 Standard` · `3-2 Website` · `4-5 Project` (각 섹션 하단 3개 행 모두 공란)
- **화면 실제 기능**(코드: `mentions-view.tsx` → `/api/scope/brand-citations`, `mentions.drilldown.tabs.citations`): 선택한 브랜드가 **언급된 답변들이 근거로 인용한 출처(도메인)** 를 보여줌.
- **작성 제안**:
  > 선택한 브랜드가 언급된 AI 답변들이 근거로 **인용한 출처(도메인)** 를 분석합니다. 해당 브랜드의 답변이 어떤 채널을 기반으로 생성됐는지 도메인·분류·인용 수로 확인합니다.
  > - 도메인 / 분류(인용 채널 카테고리) / 인용 수 / URLs / 프롬프트

### 1-2. Mention > *브랜드 선택* > 인용 출처 > *도메인 선택* — **정의 공란**
- **위치**: `2-3` · `3-2` · `4-5`
- **작성 제안**:
  > 선택한 도메인의 **하위 세부 URL**이 몇 번, 어떤 AI 엔진에서 인용되었는지 확인합니다.

### 1-3. Mention > *브랜드 선택* > 인용 출처 > 프롬프트 — **정의 공란**
- **위치**: `2-3` · `3-2` · `4-5`
- **작성 제안**:
  > 선택한 도메인이 **인용된 프롬프트** 목록을 확인합니다.
  > - 인용 수 / 퍼널(프롬프트 퍼널) / AI 엔진

### 1-4. Citation > 도메인 인용 순위 > 프롬프트 — "인용수" 항목 정의 공란
- **위치**: `2-4 Standard` · `3-3 Website` · `4-6 Project` — "1. 인용수 :" 콜론 뒤가 비어 있음(퍼널·AI 엔진은 값 있음).
- **작성 제안**:
  > **인용 수**: 해당 프롬프트의 답변에서 이 도메인이 인용된 총 횟수 (한 답변에서 같은 도메인을 여러 번 인용하면 합산).

## 2. 잘못된 정의 (Incorrect Definitions)

### 2-1. 🟥 **AI 유입 전환율** — 대시보드 성과 요약 (정의 오류, 근본)
- **위치**: `2-1 Standard Dashboard` 성과요약 #6, `4-1 Project Dashboard` Core KPI #7
- **현재(매뉴얼, 오류)**:
  > AI 유입 전환율 : *당사 도메인이 인용된 답변 수 중 사용자가 실제로 당사 도메인까지 유입된 답변의 비중*
- **문제**: 이 지표는 **답변/인용 기반이 아닙니다.** 실제로는 **GA4 사용자 기반** 지표로, "인용된 답변 중 유입된 답변의 비중"은 측정하지도, 존재하지도 않는 산식입니다.
- **정정(정본)**:
  > **AI 유입 전환율**: AI 챗봇(GA4 `AI Assistant` 채널)을 통해 사이트에 유입된 **활성 사용자 중, 전환(GA4 키 이벤트: 카탈로그·견적·시승 신청 등)을 발생시킨 사용자의 비율.**
  > - 산식: AI Assistant 채널 활성사용자의 key events 수 ÷ AI Assistant 채널 활성사용자 수 × 100 (%)
  > - 시장별 GA4 속성 연결이 필요하며, 미연결 시 "측정 대기"로 표시됩니다.

### 2-2. 🟥 **AI 유입 전환율** — AI Conversion > AI 유입 개요 (정의 오류 + 2-1과 상충)
- **위치**: `2-6 Standard` · `3-4 Website` · `4-7 Project` — "AI 유입 개요 1. AI 유입 전환율"
- **현재(매뉴얼, 오류)**:
  > AI 유입 전환율 : *사이트에 방문한 사용자 중, AI 챗봇을 통해 유입된 사용자 비율*
- **문제**: 이 문장은 **전환율이 아니라 'AI 유입 비중'(전체 방문 중 AI 채널 유입 비율)** 을 설명합니다. 게다가 **같은 지표가 2-1과 완전히 다른 정의**로 적혀 있어 상충합니다.
- **정정(정본)**: 2-1 정정과 동일 —
  > **AI 유입 전환율**: AI 챗봇(AI Assistant 채널)을 통해 유입된 활성 사용자 중 **전환(GA4 키 이벤트)한 사용자의 비율.** ( = AI 유입 사용자의 전환 이벤트 수 ÷ AI 유입 활성사용자 수 × 100 )
  > ※ '전환 격차'는 이 값과 '일반 유입 전환율'의 차이(pp)입니다.

### 2-3. 🟧 Standard Dashboard Core KPI ⑥ — 라벨/구성 불일치
- **위치**: `2-1 Standard`는 ⑥을 **"AI 유입 전환율"**(위 2-1의 오류 정의)로 표기. 반면 `3-1 Website`·`4-1 Project`는 같은 ⑥ 자리를 **"AI 타겟 출처 인용률"**(정본과 일치)로 표기 → **섹션 간 KPI 이름·정의가 다름.**
- **정본 구성**: ⑤ AI 인용 점유율 → **⑥ AI 타겟 출처 인용률** → **⑦ AI 유입 전환율** (앱 `standardDashboard.name` 순서). ⑥ 타겟 출처 인용률은 owned base가 1개일 때만 노출.
- **정정 제안**: Standard Dashboard의 KPI 목록도 Website/Project와 동일하게 **⑥ AI 타겟 출처 인용률**(정의: *당사 도메인이 인용된 답변 수 중 당사 타깃 도메인이 인용된 답변의 비중*)로 통일하고, AI 유입 전환율을 노출한다면 ⑦로 분리 + 2-1 정본 정의 사용. (실제 Standard 화면에 노출되는 KPI 목록과 대조 후 확정 권장)

## 4. AI Conversion 용어 사전 (전체)

> AI Conversion(=AI Agent Funnel > AI Conversion) 화면은 매뉴얼에서 라벨만 나열되고 **대부분 정의가 비어 있습니다**(2-6 / 3-4 / 4-7 공통). 아래는 화면에 쓰인 전 용어의 정본 정의(`messages.ko.json > standardDashboard.conversion / visits`, `lib/ga4/conversion.ts`)입니다.
>
> **관점**: AI Conversion은 **GA4 기반** 지표입니다. AI 챗봇(GA4 `AI Assistant` 채널)을 통해 유입된 사용자가 사이트에서 실제 전환하는지를 봅니다. 두 개의 렌즈로 구성됩니다 — **① 전환율(유입의 질)** 과 **② 방문 수(유입의 양)**.

### 4-1. 공통 개념

| 용어 | 정본 정의 |
| --- | --- |
| **AI Assistant 채널** | GA4 `sessionDefaultChannelGroup = "AI Assistant"`. ChatGPT·Gemini·Perplexity·Copilot·Claude 등 생성형 AI를 통한 유입을 GA4가 묶은 채널. **2026-06-05부터 집계 시작** → 초기 구간은 데이터 누적 중. |
| **AI 유입 / 일반 유입** | AI 유입 = AI Assistant 채널 유입. 일반 유입 = 그 외 전체 채널(전체 − AI). 두 코호트를 **동일 페이지 기준으로 like-for-like 비교**. |
| **활성 사용자 (activeUsers)** | 모든 전환율의 **분모(사용자 단위)**. 세션이 아니라 사용자 단위로 집계 — AI 코호트는 사용자당 세션이 적어(≈1.20 vs 1.52) 세션 기준이면 불리하기 때문. |
| **전환(키 이벤트, key events)** | GA4에 설정된 **키 이벤트 = 사이트가 정의한 전환 액션**. (Kia/IT 예시 구성: configuration_conversion 87% + request_brochure 12% + test_drive 0.4% + purchase 0% — 대부분 '관여' 신호.) 속성마다 구성이 달라 단일 수치 비교는 참고용. |
| **측정 기간** | 전환 집계 창(기본 28일, 90일 선택 가능). ※ 매뉴얼 필터 설명에 이 항목이 누락됨(3-3). |

### 4-2. ① 전환율 렌즈 — AI 유입 개요 / 엔진별 / 페이지별

| 용어 | 정본 정의 | 산식 |
| --- | --- | --- |
| **AI 유입 전환율** | AI Assistant 채널로 유입된 활성 사용자 중 전환(키 이벤트)한 비율 | AI 채널 key events ÷ AI 채널 활성사용자 × 100 (%) |
| **일반 유입 전환율** | AI 외 채널(일반 유입) 활성 사용자의 전환율 — 비교 기준선 | 일반 key events ÷ 일반 활성사용자 × 100 (%) |
| **전환 격차 (Lift)** | AI 유입 전환율 − 일반 유입 전환율. **양수면 AI 유입이 더 잘 전환**(음수면 반대) | AI 전환율 − 일반 전환율 (단위: pp) |
| **전환율·방문 수 추이** | 일자별 AI/일반 전환율(좌축 %)과 방문 수(우축 회) 동시 표시. 막대(방문 수)가 낮은 날은 표본이 적어 전환율이 크게 흔들릴 수 있음 | — |
| **AI 모델(엔진)별 전환** | 엔진(ChatGPT·Gemini)별 전환율과 활성사용자. 표본(활성사용자)이 적은 엔진은 전환율이 불안정 | 엔진별 key events ÷ 엔진별 활성사용자 |
| **페이지별 전환** | 입구/대상 URL별로 AI·일반 활성사용자와 각 전환율, 전환 격차를 비교 | 열: URL / AI 활성사용자 / 일반 활성사용자 / AI 전환율 / 일반 전환율 / 전환 격차 |

> ⚠ 참고: 한 사용자가 기간 내 여러 번 전환하면 **전환율이 100%를 넘을 수 있음**(전환 이벤트 수 ÷ 사용자 수 이므로).

### 4-3. ② 방문 수 렌즈 — AI 유입 사이트 방문 수

> 전환율(질)이 못 보여주는 **유입량·재방문·유입 경로**를 보는 보조 지표. 단위: 방문 수 = '회', 방문자 = '명'.

| 용어 | 정본 정의 | 단위/산식 |
| --- | --- | --- |
| **방문 수 (Sessions)** | AI 유입 세션 수(재방문 포함) | 회 |
| **순 방문자 (Users)** | 중복 제거 사용자 수 | 명 |
| **방문 빈도 (Frequency)** | 재방문 강도 = 사용자당 세션 수 | 방문 수 ÷ 순 방문자 |
| **입구 페이지 (Landing page)** | AI 유입이 처음 도달한 페이지 (방문 수 상위) | 열: 입구 페이지 / 방문 수 / 순 방문자 |

### 4-4. 상태·안내 문구

| 상황 | 화면 문구(정본) |
| --- | --- |
| GA4 미연동 시장 | "{brand} {country} 시장은 아직 GA4 연동 전입니다 — 시장별 GA4 속성 연결 필요(운영팀에 GA4 속성 ID + `geo-ops@example.com` 뷰어 권한 요청)." |
| GA4 연동됐으나 데이터 없음 | "측정 데이터 누적 중 — 'AI Assistant' 채널이 최근 시작돼 데이터가 쌓이는 중." |

## 부록 — 정본 Core KPI 정의 대조표 (앱 ⓘ 툴팁 기준)

| KPI | 정본 정의 | 매뉴얼 상태 |
| --- | --- | --- |
| AI 노출률 | 전체 모니터링 답변 수 중 당사 브랜드가 1회 이상 등장한 답변의 비중 | ✅ 일치 |

| AI 우호도 | 당사 브랜드 언급에 매겨진 전체 감정 신호 수 중 긍정 신호의 비중(언급 단위, 혼합 포함) — 2026-07-29 Scope 정본 정렬로 답변 단위 우세 분류에서 변경 | 🟥 **매뉴얼 재작성 필요**(구 "긍정 답변 비중" 서술) |
| AI 우선 노출도 | 당사 브랜드가 등장한 각 답변 내 최초 등장 순위의 평균값(순위 미진입 답변 제외) | ✅ 일치(제외 조건 누락은 경미) |
| AI 인용 점유율 | 전체 인용 횟수 중 사전 정의된 HMG base URL이 차지하는 비중 | 🟨 문구 정밀도(3-2) |
| AI 타겟 출처 인용률 | 당사 도메인이 인용된 답변 수 중 당사 타깃 도메인이 인용된 답변의 비중 | ✅ 일치(Web/Proj) · 🟥 Standard 라벨 불일치(2-3) |
| **AI 유입 전환율** | **GA4 'AI Assistant' 채널 활성사용자가 GA4 키 이벤트(전환)를 발생시킨 비율** | 🟥 **두 곳 모두 오류(2-1, 2-2)** |
