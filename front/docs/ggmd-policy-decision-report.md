## 2. 항목별 상세

### 2.1 프롬프트 개수 제한 · 추가 과금 〔A〕

- **결정 요청**: 계정(브랜드×국가)당 **포함 프롬프트 수**와, 초과 시 **증설 단가·상한** 정책.
- **배경**: 프롬프트 수는 측정량(= 프롬프트 × 엔진 × 측정주기)에 직접 비례해 서버·측정 리소스와 운영 규모를 결정합니다. 즉 "몇 개까지"가 곧 비용·성능의 기준선입니다.
- **선택지**
  - (A) **고정 상한** — 정액, 초과 불가. 예측 쉬움 / 확장 경직.
  - (B) **번들 + 구간 단가** — 기본 포함 수량 + 초과분 구간별 증설. 예측 + 확장 균형.
  - (C) **무제한(사용량 과금)** — 유연 / 비용 변동성 큼, 예산 통제 어려움.
- **권고안**: **(B) 번들 + 구간 단가**. 여기에 **기술 안전선(측정 파이프라인 처리량) 상한**을 별도로 두어 품질 저하를 방지.
- **필요 정보 / 결정 주체**: 목표 프롬프트 규모·증설 빈도(HMG·이노션). 앤서는 규모별 리소스 구간만 제공.
- **데드라인**: W2. 미결 시 기본 번들로 착수, 단가는 이관.

### 2.2 측정 엔진 확장 〔A〕

- **결정 요청**: 이번 검증에 포함할 **AI 엔진 확정** + 추가 엔진 도입 절차.
- **배경**: 엔진 추가 = 측정 부하·비용 증분. 엔진별 응답 특성도 달라 검증 대상 고정이 필요.
- **선택지**: (A) 현행 측정 엔진으로 고정 / (B) 회의에서 목표 엔진까지 확장.
- **권고안**: **현행 엔진 확정**(현재 대시보드 측정 엔진 기준), 추가 엔진은 **엔진당 증분비용·검증 절차로 별도 승인**.
- **결정 주체**: 우선순위=HMG·이노션, 기술 가능성=앤서.
- **데드라인**: W2.

### 2.3 권역/국가 확장 〔A〕

- **결정 요청**: 측정 대상 **국가 매트릭스(브랜드×국가) 범위**.
- **배경**: 국가 확장 = 프롬프트·엔진·수집 부하 증가. 범위 프레임을 먼저 고정해야 과금·일정이 산정됨.
- **권고안**: **현 합의/PoC 범위 확정** + 확장은 "국가당 (프롬프트×엔진) 비용" 산식으로 **절차화하여 이관**.
- **결정 주체**: HMG·이노션(범위·우선순위).
- **데드라인**: W2.

### 2.4 언어별 vs 국가 IP별 수집 〔B — 앤서 검증·전달〕

- **결정 요청**: 표준 프롬프트 측정을 **국가 IP 기반**으로 할지 **언어별**로 할지.
- **배경**: AI 답변은 접속 IP·언어에 따라 달라질 수 있어, 어느 기준이 각 시장의 실제 노출을 더 정확히 반영하는지가 쟁점.
- **앤서 검증(주도·완료 기반)**: 이미 **글로벌 대시보드(국가/IP 축)** 와 **웹사이트 대시보드(언어 축)** 두 표면에서 동일 스코프를 병렬 관측·운영 중 — 별도 셋업 없이 **두 기준의 실측 차이를 바로 비교**할 수 있습니다. 그 비교 근거를 **회의에서 전달**합니다(라이브 데이터/캡처, §4-B).
- **권고안(실측 반영)**: **다국어 국가는 언어별 분리 수집, 단일/서구권은 국가-IP 유지(하이브리드).** 실측상 비서구권(AE·ID·TH)은 현지어와 영어 노출률이 **30~49%p** 벌어져 국가-IP 집계로는 은폐되며, 서구권(US·CA·DE)은 언어 차이가 무의미(§4-B).
- **결정 주체**: 앤서 검증 결과 전달 → 3사 합의.
- **데드라인**: W3(결과 리뷰 후 확정).

### 2.5 데이터 보존 · 이력 관리 〔A〕

- **결정 요청**: 측정 이력 **보존 기간**(현장 수요 최대 5년).
- **배경**: 시계열 비교엔 일정 보존이 필수이나, 장기 보존은 **서버 비용·내부망 이관(3.2)** 이 선행되어야 감당 가능합니다.
- **선택지**: (A) 단기(예: 1년) 고정 / (B) **핫(즉시조회) + 콜드(아카이브) 티어** / (C) 장기 일괄(5년) — 비용 큼.
- **권고안**: **(B) 핫 1년(시계열 비교 기본 보장) + 콜드 아카이브 단계 확장**. 5년은 **서버이관·비용 협의 후 조건부** 확정.
- **결정 주체**: 요구기간=HMG, 비용·서버=앤서·이노션.
- **데드라인**: 서버이관 타당성(3.2, W2 게이트) 결론 후.

### 2.6 측정 주기 〔A〕

- **결정 요청**: 표준 측정의 **기본 주기**(얼마나 자주 재측정).
- **배경**: 측정 주기는 데이터 신선도를 높이지만 **측정량(=비용)에 정비례**하는 핵심 원가 변수. **데일리는 위클리의 약 7배** 규모.
- **선택지**: (A) 위클리 / (B) 데일리 / (C) 혼합.
- **권고안**: **위클리 기본** + 실시간성이 필요한 **상위 티어·특정 시장만 데일리 옵션**(추가 과금). 규모 배수는 §4-A 참조.
- **결정 주체**: 빈도·티어=HMG·이노션, 측정 가능성=앤서.
- **데드라인**: W2(과금 2.1과 연동).

### GA-1 전환 키이벤트가 권역·국가별 상이 〔A/B〕

- **결정 요청**: 권역마다 다른 전환 이벤트를 **어떻게 표준화**할지.
- **권고안**: **공통 전환 축(구매/견적/시승 등) + 권역 특수 이벤트**를 매핑표로 정의, **미정 권역은 폴백**(대체 지표/비활성 규칙, WBS 1.2.3).
- **결정 주체**: 이벤트 정의=이노션·HMG, 연동=앤서.
- **데드라인**: W3(GA 연동 선행).

### GA-3 ICT 전권역 GA 통합수집과의 중복/종속 〔A · 외부의존〕

- **결정 요청**: ICT의 전권역 GA 중앙수집 계획과 **역할 경계**.
- **권고안**: 앤서는 **"ICT 수집분을 소비(read)"** 하는 경계로 정리하고 **현행 권한모델 유지**(중복 수집 회피). ICT 향 중앙소비 시나리오를 별도 정합.
- **결정 주체**: 이노션(ICT 조율).
- **데드라인**: W2.

### ET-2 알림 정책 · 임계치 〔A/B〕

- **결정 요청**: 무엇을·언제·누구에게 알릴지(트리거·임계치·수신).
- **권고안**: **KPI 확정(1.1) 후행**. **고정 임계치 기본 + 이상탐지(추세 이탈) 옵션**, **롤 기반 수신**. 초기엔 핵심 트리거(우호도 급락·경쟁사 급증·언급률 임계 하회)만.
- **결정 주체**: 3사.
- **데드라인**: KPI 확정 후.

## 4. 부록 — 항목별 보충 근거 (앤서 준비)

### A. 규모 시나리오 배수 (2.1·2.2·2.3 과금 근거)

측정 규모는 **프롬프트 수 × 엔진 수 × 계정(브랜드×국가) 수 × 측정주기**에 **선형 비례**합니다. 티어·증설 단가는 이 배수를 근거로 합니다(절대 단가·원가는 내부 산정 별도).

| 변수 | 기준 | 시나리오 | 규모(비용) 배수 |
|---|---|---|---|
| 프롬프트 수 | 100 | 200 / 500 / 1,000 | 2× / 5× / 10× |
| 엔진 수 | 2 | 3 / 4 / 5 | 1.5× / 2× / 2.5× |
| 계정(국가) 수 | 1 | 5 / 10 / 30 | 5× / 10× / 30× |
| 측정주기 | 주 1회 | 주 2회 / 일 1회 | 2× / 7× |

→ 예: 프롬프트 200 · 엔진 3 · 국가 5 = 기준 대비 `2 × 1.5 × 5 = 15×` 규모.

### B. 2.4 수집기준 검증 근거 (앤서 실측)

website 답변을 **국가 × 언어**로 분해한 당사 노출률(현지어 vs 영어). 다국어 국가에서 언어 격차가 큼:

| 국가 | 언어별 노출률 | 언어 격차 |
|---|---|---|
| 태국(TH) | th 38.3% / en 87.0% | **48.7%p** |
| 인니(ID) | id 43.5% / en 76.9% | **33.4%p** |
| UAE(AE) | ar 46.6% / en 78.2% | **31.6%p** |
| 사우디(SA) | ar 93.6% / en 84.4% | 9.2%p |
| 벨기에(BE) | fr 85.5% / nl 93.3% | 7.8%p |
| 캐나다(CA) | en 36.8% / fr 36.6% | 0.2%p |
| 독일(DE) | de 36.7% / en 37.6% | 0.9%p |
| 미국(US) | en 36.0% / es 37.1% / ko 36.3% | ~1%p |

→ **비서구권(AE·ID·TH)은 언어가 노출을 30~49%p 좌우** — 국가-IP 단일 집계로는 은폐됨. 서구권은 무의미. ⇒ 권고 = 하이브리드(다국어 국가 언어 분리).
(※ 노출률 = 당사 브랜드 언급 답변 비중, website 스코프 실측 / 측정일 = 일 단위 누적)

### C. 2.5 보존 비용 근거

저장 비용 = **측정량 × 보존기간**에 선형(누적). 보존 5년 = 1년의 5배 + 운영기간에 따른 누적 가속. → 핫 1년 + 콜드 티어 권고의 근거.

> 절대 금액은 단위 원가 입력이 확정된 뒤 별도 산정해 제시합니다.
