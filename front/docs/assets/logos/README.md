## 메모
- 모두 SVG(벡터)라 무손실 확대 가능. 색 기준은 상위 폴더의 HMG_3사_브랜드_컬러_가이드.md 참조.
- 제네시스 엠블럼은 검정 단색이다. 다크 배경에 쓰려면 흰색 반전본(fill #FFFFFF)을 별도로 만들 것.
- 현대 로고는 네이비(Hyundai Blue) 버전. 단색 필요 시 #002C5F 기준.
- 위 파일은 위키미디어 호스팅본이다. 클라이언트 최종 납품물에는 HMG가 보유한 공식 브랜드 에셋(원본 로고 키트)으로 교체해 사용할 것(상표권은 각 사 소유).
