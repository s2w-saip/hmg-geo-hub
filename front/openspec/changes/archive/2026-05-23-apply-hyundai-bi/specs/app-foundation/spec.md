## ADDED Requirements

### Requirement: 인증 화면과 인증 뒤 헤더가 시각 토큰을 따름
로그인 페이지와 인증 뒤 `DashLayout`은 색·타이포·반경·라인 두께를 시각 토큰을 통해서만 적용해야 한다(SHALL).
하드코딩된 neutral 색이나 시스템 폰트 직접 지정은 토큰 정의 외에서 허용되지 않으며, 헤더는
좌측 워드마크 + 네비 + 우측 보조(역할 배지·로케일·로그아웃) 구조를 유지한다.

#### Scenario: 헤더가 브랜드 톤을 표현함
- **WHEN** 인증된 사용자가 어떤 보호 라우트로 이동하든
- **THEN** 헤더의 워드마크·메뉴·하단 라인 색이 브랜드 토큰에서 도출된 값으로 렌더된다

#### Scenario: 로그인 페이지가 브랜드 톤을 표현함
- **WHEN** 미인증 사용자가 로그인 페이지에 도달하면
- **THEN** 헤드라인·본문·기본 버튼·입력 포커스 색이 시각 토큰을 따른다
