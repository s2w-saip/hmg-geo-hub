## ADDED Requirements

### Requirement: 액션 결과 피드백은 토스트 표준으로 통일된다
관리자/사용자 액션의 성공 피드백은 통일된 토스트 알림 시스템을 통해 표시되어야 한다(SHALL).
토스트는 sonner를 통해 제공되며, 인증 뒤 레이아웃에서 단 한 번 마운트된다. 실패 피드백은
토스트가 아닌 호출 surface(폼/다이얼로그) 내부 inline으로 표시해 즉시 재시도가 가능해야 한다.

#### Scenario: 성공 피드백은 토스트로 표시된다
- **WHEN** 사용자 프로필 저장이 성공하면
- **THEN** 화면 모서리에 일시적 토스트가 나타나 성공 메시지를 보여준다

#### Scenario: 실패 피드백은 호출 surface 내부에 표시된다
- **WHEN** 사용자 프로필 저장이 실패하면
- **THEN** 토스트는 표시되지 않고 다이얼로그 내부에 inline 오류 메시지가 표시된다

#### Scenario: 토스트는 인증 뒤 레이아웃에서만 마운트된다
- **WHEN** 인증 뒤 레이아웃이 렌더되면
- **THEN** sonner Toaster가 단 한 번 마운트되고 모든 인증 페이지가 동일한 인스턴스를 공유한다
- **AND** 로그인 화면에는 마운트되지 않는다
