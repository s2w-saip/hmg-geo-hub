## MODIFIED Requirements

### Requirement: v1 정보구조 라우트
애플리케이션은 인증 뒤에 v1 IA를 라우트로 노출해야 한다(SHALL): 통합 대시보드, 고객 관심
대시보드, AI 답변 대시보드, 개별 프로젝트 생성, 관리자 콘솔. 추가로 접근 가능한 메인 메뉴가
없는 사용자가 도달할 빈 상태 보조 라우트(`/no-access`)를 제공한다. 모든 라우트는 로케일 접두
경로 안에서 동작하며, 라우트별 접근 가능 역할은 access-control 정책에 의해 결정된다.

#### Scenario: 인증된 사용자가 디폴트 도착 라우트에 도달함
- **WHEN** 인증된 사용자가 로그인을 완료하면
- **THEN** 사용자의 역할이 접근 가능한 라우트 중 첫 번째 라우트가 로케일 접두 경로 안에서 렌더된다

#### Scenario: 5개 메인 라우트가 모두 존재함
- **WHEN** 인증된 사용자가 통합 대시보드 / 고객 관심 / AI 답변 / 개별 프로젝트 / 관리자 콘솔
  라우트로 각각 이동하면
- **THEN** 각 라우트가 로케일 접두 경로 안에서 자체 페이지로 렌더된다(접근 정책으로 차단되지 않는 한)

#### Scenario: 미인증 접근은 리다이렉트됨
- **WHEN** 미인증 방문자가 보호 라우트(통합 대시보드 등)를 요청하면
- **THEN** 로그인 라우트로 리다이렉트된다

#### Scenario: 접근 불가 라우트 요청은 빈 상태 라우트로 리다이렉트
- **WHEN** 인증된 사용자가 자신의 역할에 허용되지 않은 메인 라우트로 이동을 시도하면
- **THEN** `/no-access` 빈 상태 라우트로 리다이렉트된다
