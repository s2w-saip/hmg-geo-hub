# Overview(대시보드) 개편 (GGMD 1차 고도화 · 피그마 611:135)

## Why
Standard 메뉴 첫 화면 "Dashboard"를 기획 확장(2026-09-01)의 "Overview — AI 답변 성과 요약"으로
바꾼다: 5-KPI 카드(값·이전 기간 대비 Δ·주별 스파크라인·경쟁사 미니값 4·상세 링크) +
국가별 GEO 현황(KPI 칩 5·국가 선택·지도·권역/국가 트리표·최대 경쟁사).

## What Changes
- `/dashboard` 라우트·권한은 그대로, 메뉴 라벨 Dashboard → Overview, 페이지 제목 "AI 답변 성과 요약".
- 종전 7 KPI 타일·KPI 추이·구성 분석 섹션 제거(추이 = 카드 스파크라인·상세 탭, 구성 = 인용 화면).
- GEO 집계 확장 `aggregateGeoKpiFromMirror`(국가×브랜드 언급·등장 답변·순위 합·감정 합 + 국가별
  답변/당사 등장/인용/공식 인용) → `buildGeo` 가 권역·국가 행에 `metrics`(KPI 5종, ours·rival) 부착.
- 지도(GeoMap)는 선택 KPI 로 채색·툴팁·범례(우선 노출도는 낮을수록 진함).
- 중립 모듈 `_data/overview-metrics.ts`(server-only 아님) — 클라이언트 컴포넌트가 지표 타입·접근자를 공유.

## Decisions
- Δ = 주 버킷 마지막 두 측정 회차 비교(스파크라인과 같은 축). 종전 일별 비교는 부분 측정일에서 65pp 처럼 튀었다.
- 경쟁사 미니값 = 언급 수 상위 4(값 정렬은 언급 1건짜리 브랜드가 100% 로 채움). 인용 점유율은
  경쟁사 값 원천(도메인→브랜드) 부재로 안내 문구.
- 권역 뷰는 종전 규칙대로 단일 활성 브랜드 필요(무필터 admin 은 안내 문구).
- GEO 노출률의 "우리" = 권한 무제한이면 SQL distinct 당사 등장 답변, 브랜드 스코프면 브랜드 합(상한 클램프).
