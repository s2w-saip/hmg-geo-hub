## 1. 문서와 생성기

- 결과 문서: 워크스페이스 루트의 `★ 수치 유의미성 점검표.html`. 레포 밖이라 커밋되지 않습니다.
  - 이 폴더에서 `python -I build_metric_meaning.py`를 실행하면 다시 만들어집니다.
- 판정 질문은 하나입니다: **이 수치가 전략팀(HMG 전략기획실)이나 마케팅 팀에 인사이트를 줄 수 있는가.**
  - 구현 여부나 값의 정확도는 판정하지 않습니다(사용자 결정).
- 파일 구성:
  - `metric_meaning_data.py`: 지표 묶기·데이터 소스 분류·판정 기준(INSIGHT_CRITERIA·TIERS·USES)·표현 개편 원칙(ELEMENTS·PRINCIPLES)·진행 현황.
  - `조사 데이터/insight_judgments.json`: 성과 지표 120개의 인사이트 판정. 등급·용도·판정 근거 4개·인사이트 문장·개선안이 들어 있습니다.
  - `조사 데이터/insight_redesign.json`: 핵심 지표 26개의 개편안(5요소 진단·바꿀 표현·헤드라인 예시)과 개편 뷰 6개의 구성.
  - `metric_meaning_template.html`: 화면 구조와 디자인(Pretendard, 디자인 토큰, 하비볼 ●◐○).
- 판정을 고칠 때는 두 JSON을 직접 고칩니다. 생성기가 아래 규칙을 검사하고, 맞지 않으면 생성이 실패합니다.
  - 등급과 판정 근거가 서로 맞는가.
  - 등급과 용도가 서로 맞는가.
  - 모든 핵심·보조 지표가 개편 뷰 하나에 들어가는가.
- 결과(2026-10-19): 핵심 지표 26 · 보조 지표 57 · 규모 정보 23 · 인사이트 없음 14. 운영 지표 55개는 점검에서 뺐습니다.

## 3. 진행 중: 개편안 시험 프로젝트 `hmg-geo-hub-test`

사용자 결정(2026-10-19):

- 폴더는 워크스페이스에 `hmg-geo-hub-test`로 만들고, 본 레포를 **로컬 git clone**해서 씁니다. 통째 복사는 하지 않습니다.
- 화면은 **기존 화면을 개편안으로 교체**합니다.
- 첫 범위는 더미 DB에 데이터가 있는 **4개 뷰**입니다.
  - 콘텐츠 기회 백로그
  - 경쟁 포지션 보드
  - 출처 공략 리스트
  - AI 추천 퍼널(GA4 단계 제외)
  - 더미 DB에 없는 칸은 '데이터 없음'으로 표시합니다.
- 더미 DB에 없는 데이터: GA4, 키워드 검색량, 소셜, 페이지 크롤. 그래서 시장 우선순위 맵의 시장 중요도 축과 페이지 성과 보드는 나중에 합니다.

새 PC에서 셋업하는 방법(Git Bash, 워크스페이스 루트 기준):

```bash
git clone --no-hardlinks hmg-geo-hub hmg-geo-hub-test
cd hmg-geo-hub-test
git remote rename origin main-repo
git remote set-url --push main-repo DISABLED-push-to-main-repo   # 시험 작업이 본 레포로 올라가지 않게 막는다
(cd front && npm ci)
# 더미 DB(hgh-synth-pg, DB hmg_synth)가 없으면 본 레포의 back/db/synth/README.md 대로 up → gen 0.1 1 → load 0.1 1
export MSYS2_ARG_CONV_EXCL="/work" SYNTH_API_NAME=hgh-test-api SYNTH_API_PORT=18190 SYNTH_AUTH_PORT=54699 SYNTH_FRONT_PORT=3300
bash back/db/synth/synth-db.sh api    # 백엔드 127.0.0.1:18190 → hmg_synth
bash back/db/synth/synth-db.sh demo   # mock 인증 54699 + 화면 http://127.0.0.1:3300/ko/login (admin@admin / admin)
```

- 포트는 본 레포 데모(백엔드 18090 · 화면 3200 · 인증 54599)와 겹치지 않게 골랐습니다. 더미 DB는 같이 읽기만 합니다.
- 교체할 화면 후보는 Global 화면입니다.
  - `/ko/dashboard`
  - `/ko/standard/answer-analysis/mention`
  - `/ko/standard/answer-analysis/citation`(+ `/prompts`)
  - `/ko/standard/ai-funnel/acr`
  - 개편 뷰와 화면을 어떻게 짝지을지는 구현 계획에서 정합니다.
