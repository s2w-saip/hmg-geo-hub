화면별 점검표

한 행은 화면에서 구분되는 하나의 표시 항목입니다. KPI 카드는 지표별로, 증감·배지·비교 값과 별도 버튼은 각각 나눴습니다. 하나의 표·차트에 속한 데이터 행·열·범례는 해당 표·차트의 점검 범위입니다. 권한·필터·데이터 상태에 따라 나타나는 항목도 포함합니다.

모든 행·모든 열에 동일한 적용 기준을 사용합니다. Before·After 모두 점검 대상이 없으면 체크박스·화살표·툴팁 없이 완전히 비우고 집계에서 제외합니다. 직접 경로에 해당 없음으로 기록된 칸을 공통 경로의 판정으로 채우지 않습니다. 대상이 있지만 아직 확인하지 못한 칸은 ☐로 남기며, 통과한 항목을 빈칸으로 바꾸지 않습니다. 기준일·상태 표시에는 계산·API 응답·접근 권한·전환 완료 판정을 붙이지 않습니다. 공통 근거는 해당 항목에 적용되는 기준만 기존 묶음의 조사 결과를 참조한다는 뜻입니다. 개별 UI 검증을 새로 완료했다는 뜻은 아닙니다. 항목에 마우스를 올리면 실제 표시된 점검 기준과 원래 조사 근거를 볼 수 있습니다.

F4 업무 기준값의 하드코딩 제거: Before에 해당 하드코딩이 없었던 항목은 Before·After 모두 빈칸으로 두고 집계에서 제외합니다. Before에서 확인된 하드코딩이 남아 있으면 ☒, 제거됐으면 ☑입니다. 제거 대상이 해당 항목에 연결돼 있지만 상태 검증이 남았을 때만 ☐를 표시합니다. 묶음에만 상수 기록이 있고 개별 항목과 연결되지 않았으면 체크를 만들지 않고 빈칸으로 둡니다. 이 경우의 불확실성은 아래 ‘F4 항목별 근거 연결 대기’에 별도로 보존하며, 하드코딩 없음으로 판정한 것은 아닙니다.

조회한 옵션을 선택하는 필터·달력은 그 조작 자체에 F4 제거 대상이 없어 빈칸입니다. 함께 조회한 KPI의 계산 상수나 공통 기간 설정을 필터의 하드코딩으로 붙이지 않습니다. 정적 업무 목록을 직접 사용하는 선택 항목(예: 프로젝트 생성의 정적 카탈로그, 고정 키워드 탭)은 F4 대상에 남깁니다. 이 적용 기준 정리는 기존 조사 기록을 사용합니다.

F1은 화면 경로 행에서만 점검합니다. 개별 카드·버튼 행은 빈칸입니다. Before는 {{N_F1_BEFORE}}개 화면만 실측했고, After는 모두 미측정입니다. 열 제목에 커서를 올리거나 누르면 점검 대상·충족 기준·확인 방법이 표시됩니다.

칸 = Before → After, 칸 색 = After 결과. 화면 행의 숫자 = 그 화면에서 ☒인 항목 수. 리뉴얼 전환 완료는 완료된 항목 수 / 전체 전환 대상 항목 수이며, 미확인은 전체에 포함하고 해당 없음은 제외합니다. 그 아래 작은 글자는 화면의 경로 상태(데이터 경로 전환 · 대체 화면 · legacy 잔존)입니다. 화면 행을 누르면 표시 항목이 펼쳐집니다. F10·완료는 After만. 구 F5는 위 필수 동일성 검증에서 별도 관리합니다.

F2 데이터 조회 SQL 복잡도해당 표시 항목의 데이터 조회 경로이 항목의 데이터를 만드는 SQL(DB 조회문)이 얼마나 복잡한지 봅니다. 화면 레이아웃이나 컴포넌트 구조를 뜻하지 않습니다.JOIN(테이블 결합) + CTE(임시 결과 정의) + GROUP BY(집계 단계) + 윈도우 함수의 개수 합이 5 이하 임시. 여러 함수가 쓰이면 가장 높은 점수를 적용합니다.운영 설정에서 실행되는 대표 SQL을 코드로 확인하고 구조를 셉니다(22번 문서 기준). 실행 시간은 F1에서 별도로 봅니다.
