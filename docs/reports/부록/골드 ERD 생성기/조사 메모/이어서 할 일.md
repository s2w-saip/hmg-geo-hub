## 3. 정적 화면 데이터 형태 (요약)

**공통: 정적 화면의 필터는 데이터를 거르지 않습니다.** `components/dash/use-filter-signal.ts:42-52` 가 필터 문자열을 해시해 숫자를 흔들 뿐입니다. 곱셈 ×0.50–0.99, 또는 ±10pp 입니다.

**Visibility**
- 픽스처 필드는 `_data/sample.ts:6-31` 입니다.
- 중앙값 = 정렬 후 `floor(n/2)` 번째 값입니다. x ≥ 중앙값이면 높음입니다.
- 필터는 `ALL_GROUPS_EXCEPT_LANGUAGE` 입니다.
- geography 옵션은 AI 답변이 측정된 국가입니다. 페이지가 있는 국가가 아닙니다.

**ACR**
- Website 와 Project 가 같은 `AcrView` 를 씁니다.
- Top5 = 후보군 포함율입니다.
- 점유 맵 = 언어 × 엔진 시트 4개, 프롬프트 8개, 반복 10칸입니다.
- 필터 16축이 모두 노출됩니다.

**소셜**
- 표 탭과 그래프 탭이 서로 다른 픽스처를 씁니다. 수치가 서로 다릅니다.
- 프로젝트 화면은 이미 `ext.ctx_*` 실데이터입니다.
- 입력 폼은 지역과 목적을 버리고 keyword 만 넘깁니다.

**GA4 방문 블록**
- 레거시는 `activeUsers` 를 기간 전체에서 중복 제거합니다.
- 필터는 AI Assistant 채널 ∧ 엔진 호스트 ∧ device ∧ newVsReturning 입니다.
- 입구 페이지는 상위 15 입니다.
- 기간은 N+1일입니다.
- 필터 4축(geography · engine · device · visitorType)이 모두 다중 선택입니다.
