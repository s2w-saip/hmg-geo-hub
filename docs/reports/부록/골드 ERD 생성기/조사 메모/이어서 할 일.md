## 2. 이 PC 에서 확인할 수 없는 것

- **카드 ④ AI 우선 노출도의 레거시 계산 방식.** 국가별 GEO 현황이 텍스트 첫 등장 순서라는 것은 확인됐습니다(`지표 점검표 생성기/progress.py:11-13`). 카드 ④ 의 근거는 레포에 없습니다.

- **GA4 기간 끝일 동등화.**
  - 레거시는 N일 전부터 오늘까지(N+1일)를 씁니다.
  - 현행 API 는 선택 속성의 최신 적재일에서 끝납니다.
  - 골드 설계는 속성별 마지막 적재일에서 끝납니다.
  - 레거시와 값을 똑같이 맞출지 정해야 합니다(DECISIONS-API.md:272).
- **ext.ctx_* 열의 의미.** 레포에 적재 코드가 없고 합성 DB 에도 데이터가 없습니다. mention_count · co_count 의 정의를 확인할 수 없습니다.
- **AI Visibility 페이지 우선순위 산정 규칙.** 정의된 것이 없습니다(`page_priority`).
