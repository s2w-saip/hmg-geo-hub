근거·합의팀은 Python·TS 운영 가능, 고객 런타임·SSO·통신 허용은 미결이다. Azure 운영·RDS 원문 읽기·TypeSafe 규칙을 추천과 분리했다. PG17·발행값 보존·변경 게이트, 읽기 API cold p95 ≤1초(10배)·반영 ≤20분을 유지한다. Next16·Node24 목표는 지원/승인·lock 검증 조건부다. 9/30 제한적 API 캐시 승인(기본 끔)과 BFF no-store를 구분한다.
화면·오류React·Tailwind·Radix, TanStack Table/Query, RHF·Zod, Recharts를 역할별로 선정했다. 서버 페이지·응답/시간 상한·세대 cursor·전체 선택을 정의하고 RSC/loader/Query의 중복 조회를 제어한다. API 오류는 throw로 연결해 0건·실패·미수집·대기·부분·오래된 값을 구별한다. 인증·다국어 이전 비용도 포함한다.
모수·발행반복 표본·외부 재시도·중복 전달·원문 수정판을 분리한다. 글로벌/웹사이트/프로젝트의 모수·앵커·제외 정책을 유지하고 결손·비교 버전을 표시한다. 실제 원문·판정·사전·보정·발행 결과를 보존하며 카드·추이·상세·export의 세대와 동시 발행·삭제 경계를 맞춘다.
권한·세션A/C/D openid-client, B Authlib를 후보로 둔다. API audience 검증·기존 계정 연결, 서버 세션·동시 refresh·CSRF·QA·철회·다운로드를 설계했다. 쿠키 서명은 토큰 서버 저장을 대신하지 않는다. 실제 접근 범위별 캐시·작업 재인가와 서명 URL의 잔여 접근을 다룬다.
수신·작업Temporal 우선 실증, Durable/PG 큐는 조건부 대안이다. PG 접수+outbox·멱등/실행 세대·단일 migration owner, RDS 지연 commit/수정/삭제와 Blob/체크포인트 대조를 명시했다. SDK/workflow 재시도를 통합하고 유료 결과 불명·늦은 응답·취소/과금을 구별한다.
AI 판단TypeSafe Choice·Noul·Score와 코드 산식을 분리한다. Python/JS SDK·고정 모델 ID·영역/입력/질문 버전별 판정을 저장하고 동시 중복을 제어한다. jev-1.13.0은 평가 후보다. 근거 검증·언어별 보류셋·모델 단종·임계값·발행 보호를 정의했다.
배포·관측Container Apps·PG Flexible Server·Blob·Key Vault·OpenTelemetry는 Azure 제품 후보다. ingress·공급 네트워크·최소 worker·콜드 시작·DB 연결·rolling 충돌을 검증한다. 5xx뿐 아니라 실패를 숨긴 200·신선도·작업 적체·결과 불명도 관측한다.
구성·실증A Next+FastAPI · B SPA+FastAPI 내 BFF · C SPA+Nest BFF+FastAPI · D Next+TS 업무/워커를 비교한다. SQLAlchemy/Alembic(A~C), Drizzle(D), OpenAPI 계약 생산자와 모듈 경계를 명시했다. 6개 실증·9개 반례 계획을 구체화하고 동일 업무·초기+12개월 총비용으로 선정한다.
전환·롤백쓰기·발행·측정 등록의 소유자, 기존 접수 차단·진행 작업 인계를 정한다. 운영 원장·QA·권한·파일·외부 연동을 대조하고 신규 쓰기를 포함한 복원 리허설 후 전환한다. 파괴적 스키마 정리는 복구 창 이후다.
