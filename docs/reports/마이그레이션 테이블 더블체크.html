A. 이관 목록 추가·확정

  1. 회차 원장 테이블 summary_cycles, summary_cycle_runs, scope_cycle_rounds를 이관 목록에 추가 부탁드립니다. 회차 숨김·마감·노출일·순번 배정은 운영 중 결정된 값이라 재계산이 불가능하고, 귀사 seed-20-ing.sql에서도 이 테이블들을 ing.cycle*의 소스로 사용하고 있습니다. scope_answer_cycle_anchors·scope_cycle_anchor_state·scope_cycle_registry_runs는 export.py에 포함된 그대로 덤프로 함께 주시면 됩니다.
  2. 3-3 보류 7개는 전부 이관으로 확정 부탁드립니다. scope_answer_anchors·scope_answer_drops는 현재 대시보드 수치 재현과 ing.answer_anchor_pin/answer_drop의 소스이고, 검수 이력 3개와 감사 로그 2개는 기능 인수와 보존 의무 때문에 저희가 보관하겠습니다.
  3. 분석 결과 4개 테이블은 ing.mention*·acr_*에 바로 적재할 수 있는 포맷(export.py CSV.gz + mig_src DDL)으로, 컷오버 직전 시점에 추출 부탁드립니다. v0 이력(결정 37)의 소스 데이터가 됩니다.
  4. 동결 데이터: export.py --frz로 추출되는 summary_generations 활성 세대 스냅샷(roster/base/target/noise)과 frz_ops_* 15종을 이관 범위에 명시해 주십시오. 3-4에는 "재계산 가능"으로만 적혀 있습니다.

B. 문서와 스크립트가 다른 부분 — 확인 요청

  1. profiles는 3-2에 이관 대상으로 적혀 있으나 seed-10-app.sql:25-27에는 "이관 대상이 아니다"로 되어 있습니다. 계정 이관은 레포 밖 load-accounts.tpl.sh로 처리되는 것으로 보입니다. 해당 스크립트와 규칙(R2/R3)을 공유해 주시고, Supabase auth.users export(이메일·password hash·confirmed_at·last_sign_in, uuid 유지)가 가능한지 알려 주십시오.
  2. project_members는 3-1에 있으나 verify-seed.sql:61에 "미이관(profiles FK)"으로 되어 있습니다. 계정 이관 후 적재 계획을 확인 부탁드립니다.
  3. standard_prompts는 3-2에 있으나 seed-10:1148에 "대상 표 없음"으로 되어 있습니다. HUB에서 어떻게 처리되는지 알려 주십시오.
  4. QA 테이블 3개는 3-3 보류인데 verify-seed.sql:63-64에 "미이관"으로 되어 있습니다. 검수 콘솔은 저희가 인수할 예정이므로 이관을 요청드립니다.
  5. scope_context_* 6개는 3-1 이관 대상이지만 mig_src 스테이징까지만 되어 있고 ext.ctx_*에 적재하는 로더가 레포에 없습니다. 로더 구현 여부·일정과, Scope 코퍼스(2026-07-07 스냅샷) 최초 적재 스크립트를 공유 부탁드립니다.

C. DB 밖 자산

  1. GA4 OAuth 계정의 property 권한 이전 절차(토큰은 환경변수에만 있음).
  2. 발행 리포트 산출물(docs/data/1-source~4-archive, .verify-manifest.json), Confluence 첨부 위치, vol.2 생성기 소스.
  3. S3 hmg-geo-hub-<env>-artifacts-* 버킷의 snap/·ddl/ 접근 권한 또는 사본. mig.archive_manifest가 비어 있어 crawl/webgeo S3 보관은 아직 실행 전으로 이해하고 있는데, 맞는지 확인 부탁드립니다.

D. 정정 및 기타
