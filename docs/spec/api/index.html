HMG-GEO-HUB API 명세

FastAPI(EC2) · 경로 접두 /v1 · 읽기 스키마 rd·app·ext · 모듈 17개 · API 179개 · 기준: DB 설계 v2.1(DB-v2.1.sql), 결정 D1~D8·A1~A17·G-01~G-26·Q1~Q19

원칙

  • 프론트는 그대로 가져온다(제품 책임자 2026-09-28). 현행 Next.js 화면·컴포넌트는 유지하고, 화면이 부르던 서버 데이터 함수(각 단위의 "대체하는 현행 코드")만 이 API 호출로 바꾼다. 응답은 현행 컴포넌트가 쓰는 타입에 맞춘다(어댑터는 프론트 데이터 계층 한 곳).
  • 기능 = API 하나, 엔드포인트 병합 금지(Q6). 모든 읽기 API 는 공통 필터 모델을 받고, 지원하지 않는 축은 meta.ignored_filters, 권한 밖 값은 meta.dropped_filters.
  • 응답 봉투 {data, meta:{surface, mode, as_of, cycles, generation, ignored_filters, dropped_filters, suppressed}}, 비율은 분자·분모 정수 동시 반환.
  • 결과 캐시·사전 집계 없음(D8). 성능 판정은 RDS 실측 게이트(현재 테스트 인프라 HMG-GEO-HUB, db.r7g.xlarge).
  • 인증: Supabase JWT(JWKS) 검증, 스코프는 서버 계산 default-deny. QA 콘솔은 별도 게이트(Q17).
