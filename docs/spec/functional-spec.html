  1. 권한 교집합: 서버가 세션에서 스코프를 계산하고 요청 필터와 교집합한다. 스코프가 비면 거부(default-deny).

  3. 관점 브랜드와 모집단: 관점 브랜드가 X 이면 프롬프트 모집단은 카탈로그 브랜드가 X 이거나 공통(HMG·브랜드 없음)인 프롬프트이고, 당사 판정은 X 다. 브랜드 스코프 계정(고객)의 현행 동작이며 대조 하네스의 기준이다(standard-filters.ts:64). 전사(hq) 계정의 무선택 상태는 모집단 전체, 당사 = HMG 3사.
  4. 옵션 창 = 데이터 창: 필터 옵션 API 는 현재 선택과 권한을 반영해 실측이 있는 조합만 돌려준다. 현행 편차: 기간 미지정 시 국가 옵션을 최근 7일 기준으로 뽑아 최신 노출 회차 45개국 중 3개국만 보인다(하네스 실측 2026-09-27). 새 구조는 스냅샷이면 최신 노출 회차, 기간이면 그 기간을 옵션 창으로 쓴다.
  5. 캐스케이드: 브랜드 → 권역 → 국가 → 언어. 상위를 풀면 하위는 비운다.
