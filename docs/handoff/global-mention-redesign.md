# Global Mention 개편 · 리뉴얼 새 외형 (정본)

목업 `docs/design/ui/mention-redesign-mockup.html`(마지막 판 `9e691ee`)을 실제 화면으로 만드는 일의 할 일 · 결정 · 진행 기록이다. 아키텍처 대공사(`docs/handoff/architecture-rebuild.md`)는 한참 뒤에 시작하므로, 이 일은 지금 구조(BFF `screens/mention_renewal.py` → 리뉴얼 화면) 위에서 한다(사용자 2026-11-05 '일단 목업대로 화면 개발부터 진행하자').

**지금 할 일:** 없음(P1~P4 끝). 남은 것: 결정 기록 '분석팀 리뷰 필요' 값 다섯의 분석팀 리뷰, 브랜드 포함 여부 라벨 정의(업스트림 U1), 아래 '후속'.

## 범위

- 새 외형은 리뉴얼 전체(사용자 2026-11-05 '셸까지 리뉴얼 전체'): 셸(회색 바탕 위 흰 판, 사이드바), 머리, 필터 칸, 카드 · 카드 머리 · 세그먼트 · 버튼 · 기준 칩 · 증감 · 툴팁. `design-rules.html`을 같이 고친다.
- 새 화면 구조는 Global Mention만. Project · Website Mention은 지금 구성 그대로(공용 부품의 새 외형만 받는다).
- 목업에 있던 머리의 'CSV 내보내기'는 페이지 단위 CSV 정의가 없어 넣지 않는다(카드 메뉴의 CSV는 그대로).
