# Website Mention 개편 계획

2026-11-02 사용자 승인. 차트 평가(종합 42점)와 중립 검증(숫자 · 구현, 설계 · 원칙) 뒤의 수정 계획이다. 구현과 다르면 이 문서를 고친다.

## 페이지가 답할 질문

우리 사이트 페이지를 겨눈 질문에 AI가 우리 브랜드를 말하는가, 어디서 빠지고 우리 대신 누가 나오는가, 어떻게 말하는가.

## 정한 것

| 항목 | 결정 | 근거 |
|---|---|---|
| 노출률 값 | 바꾸지 않는다 | 데이터 원칙. 분석 빈 답변은 업스트림 D8 |
| 분석 빈 답변 | 시장 표에 '브랜드 언급 없는 답변 수'를 Gold 값(`ment_total = 0`)으로 나란히 보인다. 경고 문구는 없다 | 사용자 결정. 'Gold 값을 나란히 보이기' 선례 |
| KPI 탭 | 4칸 카드를 선택기로 쓴다. `?kpi=`를 유지하고, 고른 KPI가 아래 구역을 바꾼다 | 디자인 규칙 '탭 아래에는 그 탭이 바꾸는 것만' |
| 브랜드 상세 | KPI 카드 머리 오른쪽 버튼으로 여는 별도 보기(`?view=brands` 유지). 열면 KPI 칸 표시가 꺼진다 | 같은 규칙. KPI와 무관한 구역. 처음 안(선택기 끝의 다섯째 칸)은 빈 세로 칸이 네 칸의 폭을 줄여 세부 수 이름이 두 줄로 꺾였다 |
| 시장 표 위치 | Mention. Overview와 같은 리더(`/v1/geo`) | Overview 값과 일치, 프롬프트 드릴은 Mention에만 있다 |
| 시장 표 기본 정렬 | 다른 브랜드가 언급된 미언급 프롬프트가 많은 순 | 하락 순은 분석 빈 답변을 맨 위로 올린다 |
| 하락 · 상승 발견 | 함께 보인다. 문턱 없음, 순서 고정 | '나빠진 것만'은 HUB의 선택이 된다 |
| 발견 문장 | 값을 제목 한 줄에 다 넣는다(미언급: 다른 브랜드 / 없음, 우호도: 긍정 · 부정). 엔진의 Δ는 엔진 표에만 | 촘촘 화면은 발견의 둘째 줄(`detail`)을 숨긴다 |
| 비교 브랜드가 여럿일 때 | 당사 대 비교 표 · 유형 구성은 마지막에 고른 브랜드를 따른다. 추이 선은 고른 브랜드 모두 | 고르는 상자는 여러 브랜드를 받는다(Global과 같은 부품) |
| Global | 동작을 바꾸지 않는다 | 표준 부품은 export · 선택 prop만 더하고 시험으로 확인한다 |

## 화면 구성

| 순서 | 구역 | 내용 |
|---|---|---|
| 1 | 이번 회차 요약 | 첫 줄 유지. 발견 4칸: 시장(언급 답변 최대 감소 · 증가), 미언급(다른 브랜드 / 없음), 엔진(전부 나열), 우호도(긍정 · 부정) |
| 2 | KPI 선택기 | 4칸(값 · Δ · 작은 추이 · 세부 수), 머리 오른쪽에 브랜드 상세. 미언급 수는 목록을 연다 |
| 3 | 현황과 추이 | 고른 KPI의 값 · 추이(당사 선만, 제목 '당사 노출률 추이'). 회차별 분자 · 분모의 툴팁 · 표 · CSV 유지 |
| 4 | 시장별 {KPI} | 시장 · 값 · Δ · 브랜드 열 · 미언급(누르면 그 시장 목록) · 다른 브랜드 언급 · 브랜드 언급 없는 답변 · 답변 · 선두 경쟁사. 정렬 4종, 국가를 누르면 국가 필터 |
| 5 | 엔진 · 유형 | 노출률 · 점유율: 엔진 표(당사 · Δ · 경쟁사 평균 · 측정 회차), 유형(기본 당사 추이, 경쟁 비교 · 구성 유지). 우호도: 감정 분포 · 유형별 감정 |
| 보기 | 브랜드 상세 | 비교 브랜드 고르기, 당사 대 비교 표(지표 3개 + 참고 2곳) · 유형별 언급 구성, 비교 브랜드 추이, 브랜드 순위표, 주별 언급 표 |
| 서랍 | 미언급 프롬프트 | 전체 · 다른 브랜드 언급 · 브랜드 언급 없음 · 일부 엔진만 빠짐(미언급 수에 들지 않음, 빠진 엔진 표시). 행마다 타겟 URL |

## 시장 표의 제한

- 브랜드 열은 계정 범위 안의 브랜드가 둘 이상일 때만 보인다. `access.clamp`가 범위 밖 브랜드를 범위 브랜드로 바꾸므로, 범위 밖 열을 읽으면 틀린 값이 나온다.
- Hyundai N은 관점이 없어 열로 읽을 수 없다. 세 열이 전체와 맞지 않는 시장이 있어 각주를 둔다.
- 이번 회차에 답변이 없는 시장은 행이 없다. 표 아래에 그 수를 적는다.
- 브랜드 언급 없는 답변은 분석 누락과 실제 무언급이 섞여 있다. 둘을 나눌 Gold 값은 없다(D8).
