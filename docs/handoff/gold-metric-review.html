  • 대상: Overview, Mention, Citation(본 화면과 하위 화면 둘, 도메인 상세 시트), ACR(β), Global › Global prompts. AI Visibility(HUB GA4·SEO, 데이터 없음)와 Admin › Global prompts(HUB 카탈로그 관리)는 Gold 화면이 아니라 뺐다.
