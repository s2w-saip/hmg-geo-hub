# Next 서비스 대조 (T14.5.3, 2026-11-07)

사용자 지시로 React를 빼고 기존 Next 서비스만 확인했다(Next → 허브 서버 → 데이터 서버). 프로덕션 빌드를 임시 복사본에서 띄웠다. 앞부분은 수정 전 공유 서버에서, 수정 확인은 임시 포트에서 돌렸다. 계정은 시험용 관리자이고, 범위 계정은 시험 안에서 만들고 지웠다.

## 그대로 둔 것

- Mention · Citation · ACR은 읽기 하나가 실패하면 본문 전체가 오류 + 다시 시도다. 수정 후 정상 조건에서는 실패가 없었다.
- 로그인 리디렉션이 `127.0.0.1:3333`을 `localhost:3333`으로 바꾼다. Next가 바인드 주소에서 만든다. 동작에는 문제 없다.
- `catalog.py`의 인용 비중 리뷰 메모는 `citation_cell`을 읽는다고 적혀 있는데 지금은 읽지 않는다.

## 돌리지 않은 것

- 프런트 전체 테스트(바뀐 파일의 테스트만 돌렸다. 실패 1건은 기준선에도 있는 `route.test.ts` 프로젝트 게이트다).
- 모든 드릴다운의 브라우저 클릭(나머지는 Next 경로로 직접 호출해 200 확인).
- 일반 브라우저 창(헤드리스 Chrome만), 동시 사용자 부하, VM.
- 실제 다음 회차 전환(지난주를 현재로 기록했다가 잡으로 되돌렸다).

스크립트는 세션 스크래치패드에 있고 커밋하지 않았다.
