### 대표 답변 규칙이 옛 표시와 다른 회차

규칙(회차 · 프롬프트 · 엔진 · 국가 · 언어마다 측정 시각이 가장 늦은 1건)을 그대로 둔다. 차이는 노출률 0.23pp 이하다. 결정은 2026-11-06 '대표 답변은 레거시를 따른다'이고 **분석팀 리뷰 필요** 표시가 그대로다.

| 회차 | 대표 답변 옛 표시 → 규칙 | 노출률 옛 표시 → 규칙 |
|---|---|---|
| Global 08-24 | 15,864 → 15,874 | 75.46 → 75.36 |
| Global 08-31 | 35,132 → 35,259 | 69.11 → 69.23 |
| Website 07-24 | 4,928 → 4,931 | 99.45 → 99.68 |
| Website 08-07 | 1,573 → 1,575 | 92.12 → 92.13 |
| Website 08-14 | 6,679 → 6,926 | 98.64 → 98.61 |

SSOT 문구와는 다른 축의 차이가 하나 더 있다. 규칙은 cycle마다 1건이고 SSOT는 '회차마다 1건'이다. 같은 회차 날짜에 cycle이 둘 이상인 Global 4개 회차에서 노출률이 다르다(조합 9,340개에 대표가 2건 이상): 07-13 75.98 ↔ 76.70, 08-10 80.38 ↔ 78.86, 08-17 76.96 ↔ 76.54, 08-24 75.36 ↔ 74.91(앞이 지금, 뒤가 회차 날짜 기준). 레거시와 같아 그대로 둔다. **분석팀 리뷰 필요**. Website 08-14는 cycle이 아니라 다른 축이다. 한 cycle · 한 사이트 안에서 같은 프롬프트를 두 나라(CZ · US 등)에서 측정한 조합 247개는 대표 답변이 측정 국가마다 나뉘는데(`silver_obt.py` 대표 판정), `geo_key`는 사이트 국가 하나로 합친다. 그래서 사이트 국가 기준으로 보면 대표가 2건이다.

Global · Website의 나머지 회차는 모니터링 · 대표 답변이 옛 표시와 답변 단위로 같다. 예외는 Website 09-18이고, 운영 스냅샷이 없는(`ready`) 사이트 답변 102건이 빠진 것이다. Global 표는 활성 릴리스 기준, Website 표는 `servable` 회차 기준이다.
