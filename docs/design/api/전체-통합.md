
# hmg-geo 재설계 통합 설계서 (API 모듈 17개, 2026-09-27)

> 기준: 설계 공용 계약 v2(`DESIGN-CONTRACT.md`), 확정 DDL `db/DB-v2.sql`, 결정 `db/DECISIONS.md`. 모듈 17개 설계 요약을 하나로 묶었다. 파일·함수 참조 중 모듈 설계에서 온 것은 "(모듈 설계 인용)"으로 표시하고, DB-v2.sql 줄 번호는 통합 단계에서 직접 대조했다.

## 1. 개요

- 백엔드는 FastAPI 하나(APIRouter 기능 모듈, 접두 `/v1`)와 적재 워커 하나(`hmg.ingest.worker`, 같은 패키지의 별도 프로세스)로 구성한다. 프론트(Next.js, Vercel icn1)는 OpenAPI 로 생성한 TS 클라이언트로 호출한다.
- 읽기 API 는 `rd`·`app`·`ext` 만 본다(A17). 쓰기 API 는 `app` 과 `app.judgment_change` INSERT 만 한다. `rd`·`ing` 반영과 Scope API 호출은 적재 모듈만 한다.
- D8(파생 층 없음)을 전 모듈에 적용했다. 모듈 제안 중 D8 위반 2건(ing.cycle 카운터 노출)은 기각했고, 결과 캐시(현행 unstable_cache 2곳 포함)는 제거한다.
- 통합 단계에서 한 결정: 공용 계층 `core`(필터·스코프·창·지표 빌더·봉투·키셋·오류·DB 세션)를 두어 7개 모듈이 각자 구현하던 창 해석·숨김 계열·자사 판정·관점 브랜드 모집단을 하나로 합쳤다. 모듈 간 순환(kpi ↔ mentions ↔ citations)은 지표 빌더를 중립 패키지 `core.measure` 로 옮겨 끊었다.

### 3.3 통합 단계에서 고친 경로·중복

1. F-1·F-2: 명세 §8 의 `GET /v1/filters?surface=` 를 `/options`·`/dates` 두 경로로 갱신한다.

4. 대시보드 KPI 7(GA4 전환)은 별도 대시보드 모듈 없이 FU-2 `view=summary` 로 공급한다.

7. 하네스 기능 번호: F08 엔진 서브 지표(K-3), F09 ACR(FU-1), F10 GA4 전환(FU-2).

### 4.2 조건부 보류(RDS 실측 게이트)

ab_own_idx(M-3), answer_stance 필터 축 사본(M-2, 채택 시 전파 함수 확장), rd.citation(prompt_key, round_date)(C-3), cit_source_idx INCLUDE 확장(C-1), rd.answer_w(project_key, round_date), rd.answer(prompt_key, round_date) INCLUDE(engine_key, cyc_key)(P-1), pg_trgm GIN, app.prompt 커버링. 전부 인덱스 또는 원자 행 사본이라 D8 적합이고, 해당 엔드포인트가 p95 1초(검색 200ms)를 넘을 때만 경로별로 추가한다(G-26 a).

### 4.3 기각

- **D8 위반**: rd.cycle.expected_units·completed_units(K-2), rd.v_cycle_ledger(AD-4). D8 예외 ③ 은 "ing.cycle 카운터(API 비노출)"다. 대체는 회차 수 비율과 rd.job 조회 시 계산이다.
- **HOT 규율 위반**: rd.citation WHERE cit_in 부분 인덱스(K-3), rd.job INCLUDE(served)(PJ-1).
- **불필요·전제 오류**: rd.cycle ASC, rd.answer_stance(entity_key), user_account(role·status), ga4_row PK 재정렬, ga4_property 인덱스, acr_prompt_run 셀 열, report_unit_value(cyc_key), seed_entity_ids UNIQUE, n_mentions 투영, prompt.excluded, answer_brand geo 커버링.

### 4.4 이름 교정

rd.dim_project.bgrp(없음), ing.cycle_round.cycle_anchor_at(없음, anchor_date), rd.cycle 카운터 열(ing.cycle 에만 있음), app.project.brand(brand_code), K-2 자리표시 열, IG-1 의 'X-Cron-Secret'·'A18'. app.hidden_market 은 이미 있다(DB-v2.sql:54).

1. **폭 10배 성능(high)**: 근거 0. 고위험 경로는 K-2 365일, 웹사이트 인용 1년(C-1·C-2), AD-2 1년, F-1 1년, AN-1 1년 조합, P-1 웹 기본 정렬, M-1·M-2 1년, FU-1 전 이력, T-1 브랜드·출처 차원.
