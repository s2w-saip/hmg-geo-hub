구성

  • 지표 탭 4개 + 브랜드 상세 → 한 페이지. 네 지표는 추이 카드 넷(2 × 2)로 한 화면에 둡니다: 값 · 증감 · 분자/분모와 당사 + 비교 브랜드 선. 고르는 동작이 없고, 한 차트에 올리면 네 차트가 같은 회차를 가리킵니다.
  • 브랜드 표는 열 머리로 정렬하고(기본 = 점유율 = 언급 수 순), 정렬한 열만 막대 · 증감으로 강조하며 추이 열이 그 지표를 따릅니다. 왼쪽 '비교' 칸으로 비교 브랜드를 넣고 빼고, 행(›)은 서랍을 엽니다.
  • HMG 행 아래 Hyundai · Kia · Genesis 각각의 값(3사 합 대 단일 브랜드 비교를 풀어 봄). 추이 카드마다 브랜드 미포함 · 포함 질문 값(Gold 카탈로그 라벨, 정의는 업스트림 확인 중).
  • 키보드: 차트는 Tab으로 들어가 ← → 로 회차, ⓘ · 툴팁은 Tab으로 열림. 차트마다 '표로 보기'(회차별 값 · 건수).
  • 외형: 회색 셸 위 흰 판 하나, 카드 = 옅은 띠(제목) + 흰 타일(내용), 무채색 + 당사 파랑 하나, 증감은 색 글자.

합친 것 (값은 모두 남음)

  • 경쟁사 분석(노출률) · (점유율) · 우선 노출도 순위표 · 브랜드 언급 순위 → 브랜드 비교 표 하나(노출률 · 점유율 · 우선 노출도 · 우호도 · 언급 수 · 프롬프트, 각 Δ · 추이).
  • 히어로 3개의 추이 → 추이 차트 하나. 엔진 카드(노출 · 점유) → 엔진 × 지표 표. 유형 카드 셋(노출 · 점유 · 감정) → 유형 × 지표 표.

새로 보이는 Gold 값 · 그대로인 것

  • 브랜드별 우호도(지금은 서랍에만), 엔진별 우호도 · 우선 노출도(Gold에 있음, 구현 때 BFF에 더함).
  • 그대로: 비교 브랜드 제한 없음(타사 15색), 서랍, 원문, HUB가 만든 기준선 · 문턱 없음, 측정 변화로 값을 숨기지 않음(7월 우호도 그대로).
  • 목업 표는 언급 상위 40개 브랜드까지 담았습니다.
