구현 기준 구조

측정 2026-11-07 20시대 KST · 커밋 54b4b30 · 이 Mac의 로컬 실행 기준

아키텍처 문서와 SSOT를 열지 않고 실행 중인 프로세스, 실제 DB, 코드, 로그에서 거꾸로 그렸다. handoff는 그림을 다 그린 뒤 기록 형식을 보려고 끝부분만 봤고, 거기서 포트 측정의 빈틈을 알아채 nginx를 다시 재서 넣었다. 그림 1 · 2에는 실행이나 데이터로 흔적이 확인된 것만 넣었고, 코드만 있는 것은 그리지 않은 것에 따로 적었다. 이름(허브 서버 · 데이터 서버 등)은 코드와 CLAUDE.md의 용어를 썼다.

구현에서 드러난 것

  1. 요청은 한 줄로 흐른다. 브라우저 → (React →) Next → 허브 서버 → 데이터 서버 → DB. 허브 서버에는 gold_db · cache_db · Silver 접속 정보가 없고, 데이터 서버에는 operations_db 접속 정보가 없다. 두 패키지는 서로 import하지 않고 shared만 같이 쓴다.
  2. 사내망 주소로 열린 것은 nginx뿐이다. 10.120.20.23:8087에서 10.0.0.0/8의 GET /ext/*만 받아 API로 넘긴다. 다른 서버와 DB는 모두 127.0.0.1만 듣는다.
  3. 평소 지표는 gold_db에서 계산한다. 데이터 서버에는 HGH_METRIC_SOURCE가 없어 Silver를 직접 세지 않는다. Silver를 읽는 것은 적재 잡, 서비스 주 잡, 마지막 수단 분기다.
  4. 지금 Silver의 내용은 이전 Gold 덤프에서 왔다. geohub_silver_db 매니페스트 1,287행의 기록 시각이 전부 같고, 행의 ext에 *_v_gold 키가 있다. 그 Silver에서 다시 gold_db로 적재한다.
  5. Silver 공개 800,951행 중 651,114행이 gold.answer_fact로 온다. 차이 149,837행은 전부 s1_normalize_answer_status = failed다. ready 스냅샷 34개의 답변 행은 계약 뷰에 나오지 않고, 읽기 역할에는 원본 테이블 권한이 없다.
  6. gold 스키마 92개 중 잡이 쓰는 것은 30개다. 나머지 62개는 소유자 외에 쓰기 권한이 없고, 그중 45개에 행이 있다. gold 스키마에는 외래키가 없다.
  7. GA4 · SEO 읽기는 빈 스키마로 향한다. analytics_reader는 analytics.*를 읽고 전부 0행이다. 행이 있는 gold.page_priority · gold.page_visibility_daily(각 158,640행), gold.ga4_value(11행)는 서버 코드가 읽지 않는다.
  8. 이 Mac에는 스케줄러가 없다. 적재 · 롤업 · 서비스 주 잡은 start-local.sh를 실행할 때 돈다.
  9. gold_before_t97(41 GB)에는 접속 설정이 없다. 프로세스 환경과 env 파일 어디에도 없고, 샘플에도 세션이 없다.

확인하지 못한 것

  • 로그인한 요청 한 건의 전체 경로. 로그인이 last_sign_in_at에 쓰기를 남겨 이번에 직접 보내지 않았다. 대신 설정, 인증 없는 요청의 응답(:5555 · :5556 모두 401), hub.log 38,524줄, api.log 66,990줄로 확인했다.
  • VM과 프로덕션. 접속하지 않았다. 이 문서는 이 Mac의 로컬 실행만 말한다.
  • 앤써, 파이프라인, 분석팀, 진짜 Silver, Bronze. 이 Mac과 저장소에서 연결 흔적을 찾지 못했다. 있는 것은 API의 audience 값(collect · analyze)뿐이다.
  • API 호출자의 신원. ext.log에 client_id 6개가 있다. 지금 등록된 클라이언트는 3개이고 전부 disabled, 이름은 local …이다.
  • 현재 gold_db가 만들어진 절차. 쓰는 잡이 없는 62개 테이블 중 55개의 행 수가 gold_before_t97과 같다는 데까지만 확인했다. 복사인지는 내용을 비교하지 않았다.
  • 값의 정확성과 지표 정의 내용. 이번 범위가 아니다.
  • 테이블별 코드 참조. Python 문자열의 SQL을 이름으로 검색한 결과다. 동적으로 조립한 이름은 놓칠 수 있고, 테스트와 .sql 파일은 세지 않았다.
