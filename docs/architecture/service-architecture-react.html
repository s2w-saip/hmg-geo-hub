현재 구현과 전환 목표

영역현재 확인한 구현React 전환 목표
프런트front/의 Next가 현재 화면과 API 중계를 담당한다. React는 별도 실행하며 기본값은 미연결이다. 현재 개발 연결은 React :3334 → Next API :3333 → 데이터 서버 :5555를 사용한다.React는 브라우저에서 실행하고, 같은 origin의 /api/*로 Hub를 호출한다. 호스팅·배포 방식은 인프라 단계에서 정한다.
이식 범위리뉴얼 원본 37개 경로 대응과 UI 사본·화면 로더를 준비했다. 미연결·계약 시험에 이어 실제 계정의 프롬프트·Overview·Kia/KR 필터 조회 응답을 확인했다. 필터 갱신은 프레임을 유지하고 데이터만 교체한다.같은 응답과 운영 스냅샷으로 원본의 화면·필터·폼·드릴다운·다운로드를 대조한다. 기존 Next 레거시의 유지·종료 범위는 T14.6에서 정한다.
인증·브라우저 APIReact는 기존 Next의 HttpOnly 쿠키 API에 연결했다. Next가 계정을 재확인하고 back/data_server에 Bearer 인증으로 요청한다. 독립 Hub로의 계약 이전은 남아 있다.Hub가 세션 쿠키 발급·갱신·삭제, 쓰기 Origin 확인, 매 요청 계정 재확인을 맡는다. 브라우저에는 로그인 토큰을 전달하거나 저장하지 않는다.
서버 분리back/data_server가 로그인·계정·입력 편집·데이터 읽기를 함께 담당한다. back/hub_server와 back/data_server는 아직 없다.T13에서 Hub와 내부 데이터 서버로 분리한다. Hub만 operations_db에 접속하고, Hub에는 gold_db 계정을 주지 않는다.
Gold·필터 조회Gold 사전 집계·캐시와, 사전 집계 지연·실패 시 최후 수단으로 직접 집계하는 처리를 구현했다. 현재 맥의 일반 필터 조회에도 Silver 어댑터 경로가 남아 있어 Gold 조회 테이블 경로로 맞출 서버 작업이 있다.cron job이 Silver 운영 스냅샷을 Gold 조회 테이블과 사전 집계로 가공한다. 필터 조회는 캐시를 먼저 보고, 없으면 gold_db 조회 테이블에서 계산한다. 사전 집계 지연·실패 시 최후 수단으로 Silver 운영 스냅샷을 직접 집계해 캐시하고, 그것도 실패하면 503 또는 해당 회차 빈칸으로 표시한다.
GA4속성 등록부와 관련 기존 코드가 있다. React의 GA4 분석 화면은 데이터 대기 상태다.결과 입력이 있다는 것만 표기한다. 실제 연결 인터페이스 개발·구현은 보류한다.

그림은 서버 안정화와 T13 이후의 목표다. 기본값 VITE_HUB_CONNECTED=false에서는 API를 호출하지 않는다. 사용자의 데이터 공급 요청으로 현재 개발 환경은 기존 Next API를 통해 연결했다. Next에 세션 확인 GET과 허용된 화면 읽기 중계를 추가했으며, 독립 Hub 연결·운영 전환은 별도로 남아 있다.

기존 UI와 같은 미연결 화면

공통 대기 화면 대신 기존 리뉴얼 컴포넌트를 표시한다. 원본 사이드바·메뉴 트리·흰 패널·운영 안내를 이식하고, KPI·분석 탭·프롬프트·관리 목록·Project 측정 설정 폼을 같은 틀에 배치했다. 데이터가 없는 분석은 값 없이 차트·표의 자리만 표시하며 설정은 읽기 전용이다. 외부 계정 대기 화면은 기존 계정 안내 막과 차트 자리를 사용한다.

미연결 표시 범위는 인증 세션이 아니다. 초기 로더와 이식 UI의 직접 요청 모두 네트워크로 나가지 않는다. 단위 12건·브라우저 38건·타입 검사·빌드·원본 384개 기준선 검사를 통과했다. 한국어·영어 대표 화면의 전체 넘침은 0이었고 영어 35개 경로에서도 브라우저 오류·API 요청이 없었다. 실제 Hub 연결·측정값·채워진 차트의 동등성·성능 검증은 서버 안정화 뒤 T14.5에서 수행한다.

기준과 문서 관계

사용자가 제공한 service-architecture-gold-node.html과 저장소에 정리된 최신 허브 서버 분리안을 React 전환용으로 옮겼다. React(브라우저) → Hub → 데이터 서버의 논리 구조를 표현하고, 호스팅·배포 배치는 인프라 단계로 남겼다. 최신 결정에 맞춰 필터 조회의 Gold 조회 테이블·cron 가공 경로, 사전 집계 지연·실패 시 최후 집계, cron의 운영 DB 쓰기 제외, 별도 지표 API 제외, GA4 연결 보류를 반영했다. 이 문서는 React 전환 구조의 기준이며, 현재 구현 아키텍처와 함께 본다.
