있지만 실제 상황으로 돌려 보지 않은 것

  • 새 회차 유입, ready → public 실제 전환, 실제 재분석. 재적재는 되돌리는 트랜잭션으로 일부 회차만 확인했다.
  • 빈 서버의 manage.py init 전체, copy_gold.py 복원 순서, 스냅샷 1,253개 전체 재적재.
  • 실제 범위 계정의 로그인 화면 흐름(토큰으로 대신 확인), React 쓰기 화면 저장, cron · VM · Docker.

그대로 뒀지만 그림과 다른 점

  • 조회용 테이블에서 OBT 계약에 없는 값(소유 · 경쟁사 출처 표시, 제품 이름, ACR 반복별 승자 · 후보)은 있는 값을 유지하고 새 회차는 빈칸이다(docs/handoff/query-tables-scope.md).
  • 데이터 서버의 'GA4 결과' 읽기는 연결되어 있지만 analytics.*가 0행이라 AI Conversion · AI Visibility 화면에 값이 없다.
  • 잡 코드 가운데 manage.py · service_week.py는 back/hub_storage에, ga4_collect.py는 back/analytics에 있다. 데이터 서버 폴더 밖이다. rollup.py · query_load.py는 data_server/metrics에 있다.
  • middleware의 '쓰기는 /api/hub/*만'은 HGH_LOCAL_READ_ONLY=1일 때의 동작이다. front/middleware.ts에 Supabase 로그인 코드가 남아 있다.
  • scripts/start-local.sh는 back/ext를 띄우지 않는다.
