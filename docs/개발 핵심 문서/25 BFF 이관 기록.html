Next 는 불러와서 보여주기만 한다 — 화면 계산을 FastAPI BFF 로 옮겼다

분석 화면의 모든 계산(합·비율·Δ·순위·정렬·상위 N·기간 해석·인사이트 규칙·기준 데이터)을 back/bff/screens 의 화면 계층으로 옮기고, Next 는 완성된 화면 모델을 받아 그리기만 하게 했다.

화면·문구·숫자는 바꾸지 않았다. 옮긴 계산은 옛 TypeScript 결과를 녹화한 골든과 Python 결과를 대조해 1:1 이식을 증명했고, 이전/이후 화면을 같은 API·같은 시각에 나란히 띄워 DOM·픽셀을 비교했다.

운영 API·인증·DB 쓰기 0건. 외부 Gold DB 는 읽기 전용 계정으로만 읽었다.

라우트 37개, 필터 변형 187건을 비교했다. 기준 사본(이관 전, :3201)과 작업본(:3200)을 같은 API·같은 시각에 띄운다. 비교 항목은 정규화 DOM, 전체 화면 픽셀, 차트 툴팁, 탭 상태다(탭 상태는 라우트 기본 변형에서 95건이고, 앞선 전체 실행에서 196건이 모두 같았다).

비교로 찾아 고친 결함

(1) 언급 분석 멘션 유형 막대: 경쟁사 한 곳의 색(bg-ink-500)이 빠졌다. 색 클래스가 Python 에만 있어서 Tailwind 가 만들지 않았기 때문이다. 프런트 타입에 받을 수 있는 색 클래스를 적어 고쳤다.

(2) 대시보드 engine=chatgpt: 인용 점유율 카드의 경쟁사 값이 항상 빠졌다. 한 번 멈춘 공유 조회가 동시 조회 표에 영구히 남아, 이후 같은 조회가 모두 20초 뒤 504 로 끝났기 때문이다. 공유 조회 자체에도 제한 시간을 걸어 고쳤다.

둘 다 재발 방지 테스트를 넣었다(커밋 41022a5).
